# Unduh laporan Monitoring

Akun dengan izin ekspor mempunyai dua pilihan format pada Monitoring KM:
Excel (.xlsx), yang dipilih pertama kali, dan CSV (.csv). Pilih format lalu tekan
Unduh Excel atau Unduh CSV. Pilihan dan tombol dikunci sementara berkas disiapkan.
Kegagalan tetap ditampilkan pada halaman; tidak ada pemberitahuan sukses palsu.

Laporan mengikuti tahun dan klaster yang sedang dipilih. Unduhan dari rincian satu
indikator tetap berupa laporan Monitoring lengkap pada tahun/cakupan tersebut.
Excel mencantumkan cakupan dan periode, indikator berurutan, filter, format angka,
serta keterangan untuk nol, target kosong, dan indikator yang belum dipantau.
CSV tetap tersedia untuk pengolahan di aplikasi lain.

Jenis berkas dari server diperiksa sebelum unduhan. Jika server lama masih
mengembalikan CSV ketika Excel dipilih, halaman menjelaskan Excel belum tersedia
dan menyarankan CSV; berkas CSV tidak diberi ekstensi XLSX.

Tampilan tombol mengikuti izin efektif dari server. Kehadiran menu Monitoring
tidak otomatis memberikan izin ekspor. Penghapusan Impor Spreadsheet tidak menghapus
ekspor; fitur impor tidak diaktifkan kembali oleh penambahan laporan Excel ini.
